# Item Helper

Клиентский Fabric-мод для Minecraft **1.21.11**. Основан на приложенном шаблоне `template-mod-template-1.21.11.zip`.

## Что делает

По нажатию бинда мод:

1. ищет нужный предмет в инвентаре (сначала активный слот, затем хотбар, затем основной инвентарь);
2. ставит его в активный слот:
   - если предмет в хотбаре — переключает выбранный слот;
   - если предмет в основном инвентаре — делает обычный `SWAP`-клик через `InventoryMenu`;
3. **проверяет**, что нужный предмет действительно появился в активном слоте;
4. выполняет ПКМ через `MultiPlayerGameMode.useItem(...)`;
5. ждёт один тик после ПКМ и возвращает предмет на исходное место, восстанавливая исходный активный слот.

Проверка защищает от рассинхрона: если сервер ещё не применил SWAP, мод не жмёт ПКМ по старому предмету, а ждёт до `HAND_CHECK_TIMEOUT_TICKS` (по умолчанию 6 тиков ≈ 300 мс). Если предмет так и не подтвердился, ПКМ не выполняется, слот возвращается, а в action bar показывается сообщение.

Обычный цикл ≈ **3 тика / 150 мс**: 1 тик на подмену, 1 тик на ПКМ, 1 тик перед возвратом. Если предмет уже в руке, ПКМ выполняется сразу. Настройки в `ItemHelperSettings.java`: `USE_DELAY_TICKS`, `RESTORE_DELAY_TICKS`, `HAND_CHECK_TIMEOUT_TICKS`.

Мод не открывает GUI инвентаря и не подменяет серверную логику: перестановки идут обычными клик-пакетами контейнера, ПКМ — ванильным `useItem`.

## Предметы и бинды

Все бинды доступны в `Настройки → Управление → Клавиши → Item Helper` и свободно перебиндиваются.

| Предмет | Бинд по умолчанию |
| --- | --- |
| Огненный заряд | `Numpad 1` |
| Око Энда | `Numpad 2` |
| Незеритовый лом | `Numpad 3` |
| Сушёная ламинария | `Numpad 4` |
| Сахар | `Numpad 5` |
| Мембрана фантома | `Numpad 6` |

Если предмета нет или он не успел подтвердиться, в action bar появится сообщение. Нажатия ставятся в очередь, но одновременно выполняется только один цикл, чтобы не смешать перестановки.

## Сборка

Для запуска Gradle нужен **JDK 25+**: `fabric-loom 1.19` требует JVM 25. Сам мод компилируется с `release 21`, поэтому в Minecraft достаточно Java 21+, Fabric Loader `>=0.20.1` и Fabric API для 1.21.11.

```bash
./gradlew build
```

Готовый jar: `build/libs/itemhelper-1.0.0.jar`. Положите его в `mods/` клиента вместе с Fabric API.
