# Item Helper

Клиентский Fabric-мод для Minecraft **1.21.11**. Основан на приложенном шаблоне `template-mod-template-1.21.11.zip`.

## Что делает

По нажатию бинда мод:

1. ищет нужный предмет в инвентаре (сначала активный слот, затем хотбар, затем основной инвентарь);
2. ставит его в активный слот:
   - если предмет в хотбаре — переключает выбранный слот;
   - если предмет в основном инвентаре — делает обычный `SWAP`-клик через `InventoryMenu`;
3. выполняет ПКМ через `MultiPlayerGameMode.useItem(...)`;
4. возвращает предмет на исходное место и восстанавливает исходный активный слот.

Цикл занимает **2 тика ≈ 100 мс** при 20 TPS: 1 тик на подмену/смену слота, затем ПКМ и возврат в одном тике. Если предмет уже в руке, ПКМ выполняется сразу (~50 мс). Настройки задержек лежат в `ItemHelperSettings.java` (`USE_DELAY_TICKS`, `RESTORE_DELAY_TICKS`).

Мод не открывает GUI инвентаря и не подменяет серверную логику: перестановки идут обычными клик-пакетами контейнера, ПКМ — ванильным `useItem`.

## Предметы и бинды

Все бинды доступны в `Настройки → Управление → Клавиши → Item Helper` и свободно перебиндиваются.

| Предмет | Бинд по умолчанию |
| --- | --- |
| Огненный заряд | `Numpad 1` |
| Око Энда | `Numpad 2` |
| Незеритовый лом | `Numpad 3` |
| Сушёная ламинария | `Numpad 4` |
| Сахар | `Numpad 5` |
| Мембрана фантома | `Numpad 6` |

Если предмета нет, в action bar появится сообщение. Нажатия ставятся в очередь, но одновременно выполняется только один цикл, чтобы не смешать перестановки.

## Сборка

Нужны Java 21+, Fabric Loader `>=0.20.1` и Fabric API для 1.21.11.

```bash
./gradlew build
```

Готовый jar: `build/libs/itemhelper-1.0.0.jar`. Положите его в `mods/` клиента вместе с Fabric API.
